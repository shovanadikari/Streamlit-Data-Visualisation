# Streamlit Data Visualisation – Interactive Retail Sales Dashboard

An interactive retail sales analytics dashboard built with **Python**, **Pandas**, **Plotly Express**, and **Streamlit**.  
This project demonstrates how modern Python libraries can be combined to create professional, web-based data visualization tools for business insights.

##  Project Overview
Retail businesses generate large volumes of transactional data that are difficult to interpret in raw tabular form.  
This dashboard provides an intuitive interface to explore sales data, track KPIs, and visualize trends across product categories, demographics, and time periods.

##  Features
- **KPI Cards**: Total Sales, Total Transactions, Items Sold, Average Transaction Value  
- **Sales Over Time**: Line chart showing monthly/seasonal trends  
- **Sales by Product Category**: Bar chart comparing Electronics, Clothing, and Beauty  
- **Sales by Gender**: Pie chart for demographic insights  
- **Customer Age Distribution**: Histogram profiling customer age groups  
- **Interactive Filters**: Sidebar controls for date range, product category, and gender  


##  Dataset
- **Transactions**: 1,000 records (2023 retail sales)  
- **Columns**: Transaction ID, Date, Customer ID, Gender, Age, Product Category, Quantity, Price per Unit, Total Amount  
- **Key Stats**:
  - Total Sales: ₹4,56,000  
  - Average Transaction Value: ₹456  
  - Items Sold: 2,514  
  - Customer Age Range: 18–64 years  

##  Tools & Technologies
- **Python 3.x** – Core programming language  
- **Pandas** – Data preprocessing and manipulation  
- **Plotly Express** – Interactive charting  
- **Streamlit** – Web-based dashboard deployment
